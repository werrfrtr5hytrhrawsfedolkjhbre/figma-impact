# 使用说明（发给同事）

这是一个 Figma 开发版插件：**改一处设计，自动找出还有哪些地方会受影响**，
并能用 AI 解释原因、生成可执行的修改指令，由你勾选确认后才应用。

---

## 一、安装（一次性）

1. 把整个文件夹放到本地任意目录（**路径尽量不含中文和空格**）
2. 打开 Figma **桌面版**
3. 菜单 `Plugins → Development → Import plugin from manifest…`
4. 选择文件夹里的 `manifest.json`

之后每次使用：`Plugins → Development → DSH 变更影响分析`

> 插件没上架，不会自动更新。我发新版本时，重新导入一次即可覆盖。

---

## 二、上手（5 步）

1. **打开插件** —— 会自动扫描当前文件
2. **选中变更源节点**
   - 图形 / 组件 / 画板 / 文本 → 点「影响节点显示」拿到**结构**影响
   - 文本想要"语义相关"的节点 → 用「AI 影响分析」，它会按需求再检索一遍
3. **写变更描述**，例如：
   - `把开关默认值改为关`
   - `把【机制】改成宋体加粗，字号 15`
4. **按需取用**
   - 「AI 影响分析」→ 结构影响 + 按需求的语义检索结果，每条带 AI 说明
     - 「语义检索」下拉三档：严（只留高置信）/ 中（默认）/ 宽（含泛相关）
     - 每条语义命中都必须给出「证据」（节点原文片段）；证据在原文里找不到的会被丢弃
     - **严档额外要求**：节点必须真的提到旧术语（例如旧的英文缩写），只是同一主题不算
     - 候选文本会先用需求里的关键词（引号片段 / 英文术语 / 中文片段）筛选，再交给 AI 判断；范围选「整个文件」时是全文件筛选，「相关范围」只在本页找
     - **语义命中的节点默认不勾选**，需要你自己判断
   - 「影响节点修改建议」→ 在上述集合里生成可勾选的修改指令
5. **勾选 → 应用**，不满意就 `Ctrl+Z` 或点「回滚本次应用」

> 三步是一条链：**② 基于 ① 的结果，③ 基于 ② 的结果**。
> 没跑上一步直接点下一步，会自动把前面的补上（点③ → 自动跑② → 自动跑①）。
> 改锚点或改范围会让整条链失效；改语义等级只让 ②③ 失效。

---

## 三、需要你自己准备的东西

**AI 相关的两个按钮需要 API Key**（没 Key 时它们是灰的）。

- 折叠面板「AI 接入」里选服务商（DeepSeek / OpenAI / 自定义）
- 填模型名和 Key → 保存 → 点「测试」验证
- Key 只存在你本机，不会同步给任何人

没有 Key 也能正常用：扫描、影响节点显示（结构）、画布标记。

---

## 四、几条必须知道的规则

**① 插件不会自动改你的稿子**

所有修改都要你勾选后点「应用」，并且可以先看 `原值 → 新值` 的对比。

**② 应用是可逆的**

- 一批修改合成一步，`Ctrl+Z` 可以整批撤销
- 另有「回滚本次应用」，用记录的原值精确还原，不依赖撤销栈

**③ 标记是临时图层**

画布上的彩色描边和气泡放在 `[DSH]` 开头的两个图层里，**不会改动你的设计稿本身**。
关闭插件会自动清理；协作者也能直接在图层里隐藏「建议气泡」层。

**④ 局部修改用括号标出来**

| 写法 | 效果 |
|---|---|
| `把【机制】改成宋体` | 只改「机制」这两个字 |
| `把[机制]改成宋体` / `把“机制”改成宋体` | 同上 |
| `把机制改成宋体` | 整段修改 |

**⑤ 范围只在「AI 影响分析」这一步生效**

- **① 影响节点显示**：永远是全文件结构（图传播 + 同容器），不受范围影响
- **② AI 影响分析**：在①的集合上按范围收敛，并检索语义
- **③ 修改建议**：直接继承②的结果

| 范围 | ② 的收敛规则 |
|---|---|
| 仅选中节点 | 只保留锚点；不做语义检索 |
| 选中节点 + 相关范围（默认） | 本页结构 + **所有跨页实例**（不按组件 id 卡）；语义检索限本页 |
| 同组件的所有实例 | 只保留实例节点（含跨页）；不做语义检索 |
| 整个文件 | 不收敛（含所有跨页同组件节点）；语义检索全文件 |

改了范围后，重新点「AI 影响分析」即可（①不用重跑）。

**⑥ 建议先在文件副本上试一次**

## 五、常见问题

**按钮是灰的**

- 没选中节点：先选一个
- 「AI 影响分析」灰：还没保存 Key
- 评审进行中：分析被冻结，等发起者结算

**提示"字体在当前环境不可用"**

字体只在装了它的机器上可用。换字体时会加载**目标字体**，换不了就是本机没有。

**提示"连不上 …"**

网络或跨域问题。用 OpenAI 需要能访问 `api.openai.com`；用中转的话，
`manifest.json` 里的 `allowedDomains` 要加上中转域名，然后重新导入插件。

**影响列表是空的**

说明这个节点既没有跳转/实例关系，也没有同容器的兄弟节点。
如果是文本，写一句变更需求再点「AI 影响分析」，它会按语义再找一遍。

## 六、能做 / 不能做（速览）

| 能做 | 不能做 |
|---|---|
| 扫描跳转、实例、样式引用 | 跨文件查找组件 |
| 三级影响（直接/间接/潜在）+ 画布标注 | 改组件定义里的默认值 |
| 文本节点的结构影响 + AI 语义检索（严/中/宽） | 修改实例内部的只读子图层 |
| AI 写说明 + 生成修改指令 | 自动应用（必须人工确认） |
| 文案、字体、字号、填充、圆角、透明度、尺寸、间距 | 位置 x/y（布局会覆盖） |
| 评审对账 + 越界审计 | 插件关闭后继续记录改动 |
